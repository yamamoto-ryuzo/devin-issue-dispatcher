skills/ — タスクプロンプトへ注入される追加指示ファイル

ファイル名別の適用:
  _all.md    全モードに常時注入
  _assess.md 評価プロンプトに注入
  _impl.md   対応（実装）プロンプトに注入
  _pr.md     再検証プロンプトに注入（AI:impl-done 付き課題の検証→push/差し戻し）
  _split.md  切り分けプロンプトに注入
  _done.md   「動作完了時の指示」— 全モードの末尾に注入
             （例: 完了時に state へ記録・特定フォーマットで報告・gh label 付与 等）

配置した .md 本文はそのままエージェントプロンプトの末尾に追加されます。
