# 完了時スキル（done）

タスク完了前に、必ず以下の動作確認を実施してください。確認が取れないまま「完了」としないこと。

## 必須確認事項

1. **動作確認を行うこと**
   - 実装した変更が実際に動くことを、単なるコード記述の完了ではなく実行結果で示す
   - lint/型チェック/ビルドが通るだけでなく、機能として動作することを確認する

2. **Playwright が利用可能なら Playwright で動作確認を行うこと**
   - UI/Web 系の変更は、ブラウザを実際に起動して該当画面・操作を確認する
   - 画面が表示される・ボタンが動く・データが正しく描画されることを目視レベルで確認する

3. **他のアプリとの連携がある場合は、必ず連携確認を行うこと**
   - API・ファイル・プロトコル等で他アプリと連携する変更は、連携先が実際に受け取れるかを確認する
   - 片側だけの実装完了で終えない

4. **QGIS などのアプリ連携がある場合は、当該アプリを実際に立ち上げて連携操作を確認すること**
   - QGIS/QField 等との連携は、アプリを起動して実際のデータ受け渡し・表示を確認する
   - 「起動できるはず」ではなく、実際に立ち上げて動いたことを証拠にする

## 確認が取れない場合

- 環境制約で動作確認ができない場合は、**何を確認できなかったかを明記**して `needs-review` 相当として扱う
- 未確認のまま「完了」を装わない
